
## 📊 Sales Dashboard README

### Overview

This is an interactive **Sales Dashboard** created using **Microsoft Excel**. The dashboard provides a visual representation of key sales metrics over time, allowing for efficient analysis and decision-making.

### 📁 File Description

* **File Name**: `Sales Dashboard.jpg`
* **Created By**: Priti Sawant
* **Tool Used**: Microsoft Excel
* **Type**: Static image of a dynamic Excel dashboard (interactive features not shown in image).

---

### 🔧 Features Included

1. **Year & Category Filters**:

   * Selectable dropdowns to filter data by year (2014–2017) and product categories (Furniture, Office Supplies, Technology).

2. **Customer Count**:

   * Horizontal bar chart showing customer count by year.

3. **Profit Gained Over Time**:

   * Line chart tracking profit growth in the Technology category.

4. **Sales By State**:

   * Heat map of the United States showing total sales by state.
   * Darker colors indicate higher sales (e.g., California with 34,886.55).

5. **Sales By Category**:

   * Bar chart comparing sales figures of Phones, Accessories, Machines, and Copiers.
   * Phones lead with 68,313.68 in sales.

6. **Top 5 Customers Making Profit**:

   * Pie chart listing top customers and their contribution to profits.
   * Example: Fred Hopkins with 2,372.01 (27%).

7. **Monthly Sales**:

   * Area chart showing total sales by month (January to December).

---

### 📌 Purpose

This dashboard was designed to:

* Track year-over-year growth.
* Identify top-performing products and customers.
* Analyze regional performance (by U.S. states).
* Monitor monthly sales trends.

---

### 🛠 How to Use

1. **Open the Excel file** (not included in this image) to interact with slicers and filters.
2. Use dropdowns to segment data by year or product category.
3. Hover over charts (in Excel) for detailed tooltips.
